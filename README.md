# Notes App

A responsive notes application built with   HTML, CSS and JavaScript.

## Features

- Create notes
- Display saved notes
- Edit existing notes
- Delete notes
- Search notes by title or keyword
- Save notes using Local Storage
- Responsive design
- Prevent empty notes from being saved

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

# Project

This project was created as a JavaScript practice project to demonstrate DOM manipulation, event handling, arrays, filtering and browser Local Storage.
